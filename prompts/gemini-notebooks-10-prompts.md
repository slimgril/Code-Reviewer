## ① 資料重點整理器（最常用）

**用途**：整理 PDF / 課程 / 長文章
**難度**：⭐
**執行時間**：2-3 分鐘

### Prompt 完整文本

```
請根據 Notebook 中的資料，整理「最重要的 20% 核心內容」。

主題：【主題】

輸出格式：
1. 5 個關鍵重點（條列）
2. 每點用一句話解釋
3. 3 個最值得記住的概念
4. 一句總結（白話版）

要求：
- 使用簡單語言
- 避免冗長
- 聚焦可理解與可記憶
```

### 使用範例

**填寫範例**：

- 主題：機器學習基礎概念

**預期輸出**：

- 5 個核心概念清單
- 簡短解釋
- 最易混淆的 3 個重點
- 一句白話總結

### 適用情景

✅ 快速消化課程內容
✅ 提取論文重點
✅ 整理會議紀錄
✅ 準備考試複習

## ② 結構拆解器（做課程／文章用）

**用途**：清晰結構化內容
**難度**：⭐⭐
**執行時間**：3-5 分鐘

### Prompt 完整文本

```
請根據 Notebook 資料，將內容拆解成「清晰結構」。

主題：【主題】

輸出格式：
1. 三大主架構
2. 每個架構下 3–5 個子重點
3. 每個子重點附一句說明

要求：
- 結構清楚
- 適合用於教學或簡報
- 避免冗長
- 聚焦可理解與可記憶
```

### 使用範例

**填寫範例**：

- 主題：有效溝通技巧

**預期輸出**：

```
主架構一：傾聽技巧
 - 認真聽
 - 提問澄清
 - 反思確認

主架構二：表達技巧
 - 清楚陳述
 - 控制語速
 - 觀察回應

主架構三：反饋技巧
 - 具體舉例
 - 正向框架
 - 行動建議
```

### 適用情景

✅ 設計課程大綱
✅ 寫教科書章節
✅ 製作思維導圖
✅ 規劃教學流程

## ③ 內容生成器（部落格／IG／電子報）

**用途**：直接生成發佈內容
**難度**：⭐⭐
**執行時間**：5-10 分鐘

### Prompt 完整文本

```
請根據 Notebook 中的資料，生成一篇內容。

主題：【主題】
目標讀者：【受眾】

輸出格式：
1. 開頭（吸引注意）
2. 3–5 個重點段落
3. 結尾（總結＋行動引導）

風格：
- 清楚易讀
- 有邏輯
- 避免學術感
```

### 使用範例

**填寫範例**：

- 主題：遠端工作效率提升
- 受眾：上班族、創業者

**預期輸出**：

- 開頭：為什麼遠端工作容易分心？
- 段落 1：建立固定的工作空間
- 段落 2：制定明確的時間表
- 段落 3：使用專注工具和技巧
- 段落 4：定期休息和運動
- 結尾：現在就試試看這些方法

### 適用情景

✅ 寫部落格貼文
✅ 生成 IG Carousel 文案
✅ 製作電子報內容
✅ 準備社群媒體素材

## ④ 高轉換文案生成器（變現用）

**用途**：寫高轉換的銷售文案
**難度**：⭐⭐⭐
**執行時間**：10-15 分鐘

### Prompt 完整文本

```
請根據 Notebook 資料，寫一篇高轉換文案。

產品／主題：【填寫】

輸出格式：
1. Hook（吸引開頭）
2. 問題痛點
3. 解決方案
4. 產品價值
5. 行動呼籲 CTA

要求：
- 語氣有說服力
- 強調價值與結果
```

### 使用範例

**填寫範例**：

- 產品：線上課程 - AI 商務應用

**預期輸出**：

1. Hook：你是否還在用傳統方法做商務決策？
2. 痛點：浪費時間、效率低、決策延遲
3. 方案：學習 AI 工具快速分析數據

5. CTA：立即報名，享有限時 30% 折扣

✅ 寫銷售頁文案

✅ 設計登陸頁內容

## ⑦ 深度分析器（進階用）

**用途**：進行深入分析而非表面整理
**難度**：⭐⭐⭐
**執行時間**：15-20 分鐘

### Prompt 完整文本

```
請根據 Notebook 中的資料，進行深入分析。

主題：【主題】

輸出格式：
1. 核心觀點
2. 支持論點（3–5 點）
3. 可能盲點
4. 延伸思考

要求：
- 有洞察
- 避免表面整理
```

### 使用範例

**填寫範例**：

- 主題：遠端工作是未來趨勢嗎？

**預期輸出**：

1. 核心觀點：遠端工作不是絕對趨勢，而是混合模式將成主流
2. 支持論點：
 - 技術成熟，協作工具完善
 - 員工生活品質提升，留任率增加
 - 降低辦公室成本
 - 但某些工作需要當面溝通
 - 公司文化建立需要調整
3. 可能盲點：
 - 忽視某些職位不適合遠端
 - 溝通成本被低估
4. 延伸思考：如何平衡效率與人文關懷

### 適用情景

✅ 撰寫評論文章
✅ 進行市場分析
✅ 執行策略評估
✅ 撰寫研究報告

## ⑧ 比較分析器（做決策用）

**用途**：清楚對比兩項事物以協助決策
**難度**：⭐⭐
**執行時間**：5-10 分鐘

### Prompt 完整文本

```
請根據 Notebook 資料，比較以下內容：

比較主題：【A vs B】

輸出格式：
1. 各自優點
2. 各自缺點
3. 適用情境
4. 建議選擇

要求：
- 清楚對比
- 避免模糊結論
```

### 使用範例

**填寫範例**：

- A vs B：Notion vs Excel

**預期輸出**：

```
【Notion 優點】
- 資料庫功能強大
- 可視化呈現好
- 協作功能完善

【Excel 優點】
- 公式運算快
- 圖表製作成熟
- 相容性高

【Notion 缺點】
- 學習曲線陡
- 公式有限制

【Excel 缺點】
- 協作體驗差
- 資料組織彈性低

【適用情境】
- Notion：知識管理、專案追蹤
- Excel：財務分析、大數據運算

【建議】
看你的優先順序：協作選 Notion，計算選 Excel
```

### 適用情景

✅ 選擇軟體工具
✅ 評估投資方案
✅ 比較供應商方案
✅ 技術方案評估

## 💡 進階使用技巧

### 一句話原則

**提示清晰度決定輸出品質**

好的提示應包含：

1. ✅ 明確目標（做什麼）
2. ✅ 具體主題（針對什麼）
3. ✅ 清楚格式（怎樣輸出）
4. ✅ 具體要求（什麼限制／風格）

**完整工作流程範例**：

```
1. 用「資料重點整理器」 → 提取核心內容
```

不滿意第一稿？加上 feedback：

- 要求「更簡潔」或「更詳細」
- 調整「語氣」或「風格」
- 追加「舉例」或「數據」

## ❓ 常見問題 Q&A

**Q：哪個模板最好用？**
A：「①資料重點整理器」最常用，快速見效。

**Q：可以組合使用多個模板嗎？**
A：完全可以！例：整理→拆解→生成→優化。

**Q：如何改進 AI 輸出品質？**
A：

- 調整【主題】的細節程度
- 補充背景資訊
- 給具體例子
- 指定輸出格式

**Q：模板適合所有內容嗎？**
A：適合文字內容。圖表、程式碼可補充說明。

**Q：複製提示詞後要修改什麼？**
A：只需替換【】內的佔位符，其他保持原樣。

**Q：一次可以輸入多少資料？**
A：Gemini Notebooks 支援長文本，可直接貼入整個 PDF 內容。

**Q：如果不滿意結果怎麼辦？**
A：

- 追加指令「更簡潔/詳細」
- 說「用另一個角度重寫」
- 指定「舉 3 個例子」
